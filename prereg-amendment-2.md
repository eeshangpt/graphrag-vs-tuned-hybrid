Status (as drafted): proposed after an independent agy audit of the wave-2 deliverable (`audit-agy-r1.md`). Amendment 1 is frozen (tag `prereg-162-frozen`); it was meant to be tagged before any confirmatory data existed (see timing disclosure above). Four small changes.

A2.1 Confirmatory sample excludes the exploratory slice. The first 50 indices of the seed-20261005 permutation were used for design decisions (prompt, H2 margin, replacement H1, gate threshold; wave2-bugcheck.md sec 6). Confirmatory n = 950 per dataset (permutation positions 51-1000); the first 50 are reported separately as exploratory. Replaces "n=1,000" in amendment 1 sec 2 (H1, H2, kill rule). Power at n=950 for H2 (equivalence, margin 4 F1): 0.94 (SD 0.35), 0.73 (SD 0.45), 0.67 (SD 0.47) (n=1,000: 0.95, 0.76, 0.70).
A2.2 Leakage magnitude reported, not gated. Besides the gate (F1 on rows whose context lacks every gold string, under the headline refusal prompt, below 0.10), report the same statistic under the secondary guess prompt as the "memory-fill propensity" of the generator (pilot: 0.35-0.53). It is descriptive, has no threshold and changes no decision.
A2.3 B=2000 consistency rule. B=2000 gets the same H2 classification as B=1000, computed identically and labelled sensitivity. A result is called "robust to budget" only if the H2 class is the same at both budgets; otherwise "budget-sensitive". No separate hypothesis test or multiplicity adjustment is added; B=1000 stays the single primary.
A2.4 Cost reporting. The H3 table additionally reports (a) the graph arm's per-query LLM triple-filter cost, measured in the full run if the filter is on, else estimated from the paper's filter prompt (labelled estimate); (b) local CPU time priced at a declared reference rate as a sensitivity row (the rate is a declared assumption, not a measurement). V* is reported as "undefined" if the graph's per-query cost exceeds the hybrid's.
Not changed: the H2 margin +/-4 F1 (decided by the owner; the published +2.9 gap lies inside it and an "equivalent" verdict cannot rule that effect out, stated in amendment 1), the kill rule (registered in prereg.md).
